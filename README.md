# Garage Manager

Garage repair management: vehicles, owners, job cards, diagnosis, owner notifications, estimates, invoices.

| Path | What |
|---|---|
| `output/garage-repair-spec.md` | Spec (UC / AC / NFR IDs) — source of truth for all later stages |
| `output/garage-db-design.md` | Database design (18 tables, indexes, migration rules) |
| `output/garage-auth-design.md` | Auth & security foundation — token strategy, role/section taxonomy, guards, hardening |
| `output/garage-api-endpoints.md` | **Generated** endpoint × section × role table (67 endpoints) — regenerated by `npm run test:e2e` |
| `backend/` | NestJS 10 + TypeORM + PostgreSQL API (`/api/v1`, Swagger at `/docs`) |
| `frontend/` | Next.js 16 (App Router, Tailwind) — staff app + public `/portal/[token]` owner page |

## Run locally

```bash
# backend (needs Postgres; copy .env.example → .env and set DB_* / JWT_ACCESS_SECRET)
cd backend && npm install && npm run start:dev     # http://localhost:4000/api/v1/health

# frontend
cd frontend && npm install && npm run dev          # http://localhost:3000
```

## Database migrations

Schema changes go through TypeORM migrations only — `synchronize` is always off.
Migrations live in `backend/src/core/database/migrations/`.

```bash
cd backend
npm run migration:generate -- AddVehicles   # diff entities vs DB → new migration file
npm run migration:create -- SeedRoles       # empty migration for hand-written SQL/data
npm run migration:run                       # apply pending
npm run migration:revert                    # roll back the last one
npm run migration:show                      # list applied [X] / pending [ ]
```

After generating, follow the hand-edit checklist in `output/garage-db-design.md` → Migration Strategy
(dedupe shared enum types, then confirm `migration:generate -- Check` reports "No changes").

Set `DB_MIGRATIONS_RUN=true` to apply pending migrations automatically on app start (e.g. in deployments).

Quality gates: `npm run lint:check`, `npm run build`, `npm run test:e2e` (backend); `npm run lint`, `npm run build` (frontend).

## Background jobs & integrations

- **Notification worker** (`NOTIFICATIONS_WORKER_ENABLED`, `NOTIFICATIONS_POLL_MS`): delivers queued owner messages; Postgres is the queue (`FOR UPDATE SKIP LOCKED`, safe with several API instances); 3 attempts with backoff, then `FAILED` (retry from the API).
- **Service reminders**: hourly sweep, sends at 09:00 garage-local time for vehicles due within 7 days.
- **Email**: `MAIL_DRIVER=log` (dev, writes to the log) or `smtp` (nodemailer, `MAIL_*`).
- **SMS**: `SMS_PROVIDER=console` (dev) or `twilio` (`TWILIO_*`).
- **Files**: `STORAGE_DRIVER=local` (`STORAGE_LOCAL_DIR`); S3 not implemented yet.
